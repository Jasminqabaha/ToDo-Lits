# To Do List ✅

A sleek and intuitive to-do list app built with **React**, **Context API**, and **Tailwind CSS**. Designed for simplicity and productivity, To Do List lets you manage tasks with ease — from adding and editing to filtering and bulk deletion.

## 🚀 Features

- ✅ Add new tasks via input
- ✏️ Edit existing tasks
- 🗑️ Delete individual tasks with confirmation
- ✔️ Mark tasks as done
- 📂 Filter by: All / Done / To Do
- 🔄 Bulk delete for done tasks or all tasks
- 🎨 Responsive UI with Tailwind CSS

## 🛠️ Tech Stack

- [React](https://reactjs.org/) with [Vite](https://vitejs.dev/)
- [Context API](https://reactjs.org/docs/context.html) for state management
- [Tailwind CSS](https://tailwindcss.com/) for styling
